# SharedInfo

Shared tutorials, simulations, and reference material.

## Tutorials

- [GitHub and ChatGPT Setup](tutorials/github-chatgpt-setup/) — Create a GitHub account and repository, connect GitHub to ChatGPT, and use ChatGPT to create and edit files. [Open the live tutorial](https://bortlip.github.io/SharedInfo/tutorials/github-chatgpt-setup/tutorial.html).

## Simulations

- [Boarding Rush](simulations/group-aware-boarding/) — Race six aircraft boarding methods while modeling families, children, assisted parties, load factor, party-size distributions, carry-ons, and imperfect sequence compliance. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/group-aware-boarding/). [Read how the model works](simulations/group-aware-boarding/MODEL.md).
- [Pocket Prix](simulations/pocket-prix/) — Watch autonomous drivers race with distinct personalities, physical grip, passing, collisions, damage, recovery vehicles, sound, slick spots, and optional chaos events. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/pocket-prix/).
- [Neural Playground](simulations/neural-playground/) — Train a perceptron or tiny hidden-layer network in the browser, edit 2D datasets, watch decision boundaries move, and trace activations through the network. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/neural-playground/).
- [Perception Rover Lab](simulations/perception-rover/) — Drive a simulated rover, collect and label camera frames, train a tiny neural network in the browser, validate it on held-out data, and deploy it as an autopilot. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/perception-rover/).
- [POV RL Racing Lab](simulations/rl-racing-lab/) — Train 1–10 shared-policy drivers from selectable Driver-POV or overhead neural images plus vehicle/track context with actor-critic/PPO backpropagation, then benchmark the frozen brain in four-car races across multiple tracks. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/rl-racing-lab/).
- [Schelling Segregation Lab](simulations/schelling-segregation/) — Explore neighborhood sorting with 2–20 groups, configurable local rules, deterministic seeds, live metrics, and A/B comparison. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/schelling-segregation/).
- [Downs-Thomson Traffic Lab](simulations/downs-thomson-paradox/) — Follow 100 persistent commuters as individual cars queue through a finite-capacity road network, transit riders catch scheduled trains, and a five-minute tunnel changes the mode-choice equilibrium. [Open the released simulation](https://bortlip.github.io/SharedInfo/simulations/downs-thomson-paradox/).
- [Green Hackenbush Garden](simulations/green-hackenbush/) — Play grounded graph games, challenge a perfect computer, generate custom gardens, and explore the Sprague-Grundy and XOR reasoning behind every position. [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/green-hackenbush/).
