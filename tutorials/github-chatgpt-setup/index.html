Use GitHub with ChatGPT

Create a GitHub account and repository, connect it to ChatGPT, and let ChatGPT create and edit files — no programming or Git commands required.

✓ Create an account ✓ Connect the plugin ✓ Edit a README ✓ Review a pull request
🧭

1. The basic ideas

GitHubA website for storing projects and keeping a history of their files.
Repository (repo)A project folder on GitHub.
CommitA saved change or checkpoint.
GitThe underlying system GitHub uses to track changes.

You do not need to learn Git commands for this tutorial.

2. Create a GitHub account

  1. Go to github.com.
  2. Select Sign up.
  3. Use an email address, or choose Continue with Google or Continue with Apple.
  4. Choose a username and verify your email address.
Recommended: Enable two-factor authentication and save the recovery codes somewhere safe.
↗ Creating a GitHub account
📁

3. Create your first repository

  1. Select the + button near the upper-right corner of GitHub.
  2. Select New repository.
  3. Name it my-chatgpt-files.
  4. Select Private.
  5. Turn on Add a README file.
  6. Select Create repository.

The README is the repository's introductory page. Leave its default text in place; updating it will be ChatGPT's first task.

Do not store secrets: Keep passwords, recovery codes, API keys, and financial information out of the repository.
↗ Creating a new repository
🔌

4. Connect GitHub to ChatGPT

  1. In ChatGPT, open Plugins.
  2. Scroll down and select Browse plugins.
  3. Find the GitHub plugin and choose Connect.
  4. On GitHub, authorize the ChatGPT Codex Connector.
  5. Choose Only select repositories and select my-chatgpt-files.
  6. Complete the installation and return to ChatGPT.
A newly connected repository may take a few minutes to appear.
↗ Plugins in ChatGPT and Codex ↗ ChatGPT Codex Connector
✨

5. Give ChatGPT its first task

Start a normal ChatGPT conversation and enter:

Use GitHub to update README.md in my repository named my-chatgpt-files.

Replace the default README with a short, beginner-friendly explanation that this repository contains files and notes that I manage with ChatGPT.

ChatGPT may ask you to approve the action. Approve it when it matches what you requested.

🔎

6. Check the result

Return to GitHub, open the my-chatgpt-files repository, and select README.md. You should see the text created by ChatGPT.

GitHub keeps a record of the change, allowing you to inspect what changed and see earlier versions later.

📝

7. Ask ChatGPT to create a file

Create a file named ideas.md in my repository named my-chatgpt-files.

Add the heading "Ideas" and a short list of useful things I could store in this repository.

Return to GitHub and confirm that ideas.md appears. You have now edited an existing file and created a new one.

💬

8. How to ask for future changes

A useful request normally needs the repository name, the desired change, and any important requirements.

Update ideas.md in my repository named my-chatgpt-files.

Organize the ideas into Personal, Home, and Work sections.

Concentrate on describing the result you want.

⑂

9. What a pull request is

A pull request (PR) lets you review proposed changes before adding them to the repository's main version. It is useful for larger or important changes.

Make the changes on a new branch and open a pull request for me to review.

Review and merge a PR

  1. Open the pull request link in GitHub.
  2. Read the summary on the Conversation tab.
  3. Open Files changed.
  4. Review the changes. Green lines were added; red lines were removed.
  5. Ask ChatGPT to correct anything that is wrong.
  6. Select Merge pull request, then Confirm merge.
Merge means accepting the proposed changes and adding them to the repository's main version.

10. Give ChatGPT access to another repository

  1. Open GitHub Settings.
  2. Open Applications.
  3. Find ChatGPT Codex Connector under installed GitHub apps.
  4. Select Configure.
  5. Add the repository under Repository access and save.

You normally do not need to reinstall the connector; just add the new repository to its allowed list.

🛡️

Basic safety

  • Do not store passwords, recovery codes, API keys, or financial information in GitHub.
  • Give the connector access only to repositories it needs.
  • Review important changes after ChatGPT makes them.
  • Use a pull request when you want a separate review step.
  • Remove repository access when it is no longer needed.
