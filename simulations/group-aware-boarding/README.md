# Group-Aware Aircraft Boarding Simulator

An interactive, deterministic simulator for comparing six aircraft boarding methods while keeping families and assisted parties together.

- [Open the live simulator](https://bortlip.github.io/SharedInfo/simulations/group-aware-boarding/simulator.html)
- [Read how the simulation works](MODEL.md)
- [View the simulator source](simulator.html)
- [View the redirect page](index.html)

The simulator compares random, strict back-to-front, strict front-to-back, airline zones, group-safe WilMA, and group-safe Steffen boarding. It models partial loads, family composition, children, assisted travelers and companions, carry-ons, walking and seating speeds, aisle blocking, seat interference, priority policies, and imperfect sequence compliance.

The folder's GitHub Pages URL redirects to the explicit `simulator.html` page.
