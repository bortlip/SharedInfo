# Development Simulator

This folder contains the non-released working version of the boarding simulator.

Feature work, UI experiments, event prototypes, and model changes belong here. The development page may be incomplete or unstable and is not the public release.

- [Open the development simulator on GitHub Pages](https://bortlip.github.io/SharedInfo/simulations/group-aware-boarding/dev/simulator.html)
- [Open the released simulator](https://bortlip.github.io/SharedInfo/simulations/group-aware-boarding/)

## Hard rules

1. Do not edit the frozen root `simulator.html`.
2. Do not edit `dist/simulator.html` or the root `index.html` during ordinary development.
3. Every repository change goes through a PR.
4. Only Barry merges PRs.
5. A release PR is created only after Barry explicitly approves promoting a development version.
