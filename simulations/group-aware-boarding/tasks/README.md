## Status vocabulary

- **Idea** — documented but not selected
- **Designing** — open questions are being resolved
- **Ready** — bounded enough to implement
- **In progress** — active feature branch and PR work
- **Done in dev** — merged into the development version, not released
- **Released** — explicitly promoted to `dist/` through a user-merged release PR

All tasks begin as **Idea**.
