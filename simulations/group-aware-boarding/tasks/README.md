## Status vocabulary

- **Idea** — documented but not selected
- **Designing** — open questions are being resolved
- **Ready** — bounded enough to implement
- **In progress** — active feature branch and PR work
- **Done in candidate** — merged into `src/` and `dist/`, but not yet promoted to the released root file
- **Released** — explicitly promoted to root `simulator.html` through a dedicated PR merged by Barry

All tasks begin as **Idea** unless their write-up explicitly records partial structural completion.
