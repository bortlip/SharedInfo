# TASK-016: Accessibility, Mobile, and Sound

**Status:** Idea

## Goal

Ensure that a more animated, colorful simulator remains usable with different devices and accessibility needs.

## Accessibility

- keyboard selection and controls
- visible focus states
- reduced-motion mode
- non-color indicators for passenger type and state
- high-contrast option
- screen-reader summaries of race status and results
- accessible charts and data tables
- pauseable event announcements

## Mobile

- one or two enlarged cabins at a time
- swipe or tab between methods
- bottom-sheet inspector
- compact scenario cards
- no hover-only information

## Sound

Optional subtle audio could include boarding chimes, bag thumps, conflict cues, and finish sounds. Sound must default to off or require an explicit first interaction, include independent volume control, and have descriptive visual equivalents.

## Acceptance criteria

- Core functions work without a mouse
- Reduced-motion mode removes nonessential animation
- Tooltips have touch and keyboard alternatives
- Sound is optional and never carries unique information
- Mobile layout supports the complete run and results workflow
