# Design Documents

These documents define the direction of the simulator before implementation work begins.

- [Product Vision](PRODUCT_VISION.md) — what the simulator should feel like and what it is trying to become
- [Fun-First UI Direction](FUN_FIRST_UI_DIRECTION.md) — interaction, animation, character, and presentation principles
- [Event and Character System](EVENT_AND_CHARACTER_SYSTEM.md) — a deterministic framework for disruptions such as "Barbara"
- [Architecture Direction](ARCHITECTURE_DIRECTION.md) — how to grow beyond one monolithic HTML file while retaining a standalone build
- [Release and Development Workflow](RELEASE_AND_DEVELOPMENT_WORKFLOW.md) — protected files, development flow, and release promotion

Design documents can evolve through normal PRs. They do not authorize changing released artifacts.
