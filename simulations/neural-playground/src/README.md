# Neural Playground modular source

This folder is the editable browser-native source for Neural Playground.

- `index.html` runs the modular source directly.
- `styles.css` contains the complete UI styling.
- `js/` contains dependency-ordered plain JavaScript files.

No bundler or package manager is required. The released `../simulator.html` loads these same source files with `src/`-prefixed paths, matching the Pocket Prix layout.
